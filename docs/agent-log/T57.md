## 2026-11-20 · T57 Dashboard v2 foundation: theme, compact provenance, in-session navigation · implementer (opus-5.5)
- Did:
  - **Router.** `app/Home.py` is now only `st.navigation(position="top")` over `app/views/markets.py` (the old Home, moved) and `app/pages/*.py`. The URL paths are the same as before (`/`, `/Macro`, `/Cross_checks`, …). `client.showSidebarNavigation = false`.
  - **In-session selection.** The tiles, watchlist rows, biggest moves and overview cards are each drawn by `panels` as markup and placed under a transparent `st.button`. Its callback sets `st.query_params["id"]`. The markup has no `href`, no `target` and no `title`. The ETF-proxy fold is an `st.expander`, so its rows can hold buttons too. The health badge opens Data health with `st.switch_page`.
  - **Compact provenance.** `value_cell(compact=True)` draws a focusable tier glyph, a CSS tooltip (field, glyph and tier, as-of, source) and an `aria-label` with the full provenance. `change_cell(compact=True)` draws a tinted pill. `glyph=False` keeps its provenance for screen readers only, for a change printed beside its value. `Provenance.flags` prints proxy, IEX, fallback and HYPOTHETICAL as visible tags. `kit.glyph_legend(hidden)` and `kit.details(title, html)` (an `st.dialog`) are new. Markets has a "Source details" button that opens the lineage.
  - **Theme.** The P-022 tokens are in `theme.py` and `config.toml`. Cards have no borders. Failed and warn markers are amber (`values.status_marker`, `kit.STATUS_COLOUR`). Red is used only for down.
  - **Caches.** `kit`'s serving and recent-table caches are keyed on `data.data_version()`, through `kit.version()`, which returns `""` if the store cannot be listed.
- Decisions:
  - Macro's `_link` stays a full-reload link for now, on the planner's ruling. In-session navigation for it moves to T59.
  - Inter is first in the font stack but is not downloaded. There is no CDN and no vendored font, so it shows only where Inter is installed.
  - The phone page list stays in Streamlit's sidebar drawer. On a narrow screen, `position="top"` moves it there, so the sidebar toggle is not hidden.
- Gotchas:
  - In `st.markdown`, an `<a>` holding `<div>`s is split into several fragments. Each selectable item is wrapped in a `<div class="db-pickbody">`.
  - AppTest does not render a dialog's body, so the test records the call to `kit.details` instead.
  - Each synthetic store keeps one shared DuckDB connection with native threads (T56). The new test files close the connections they opened, or the full suite fails with "can't start new thread".
