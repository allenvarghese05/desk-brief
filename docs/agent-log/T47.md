## 2026-11-19 · T47 Cboe volatility indices · implementer (opus-5.5)
- Did:
  - `sources/cboe.py`: generalised from VIX to a per-symbol table, `SYMBOL_SPECS`. It holds each
    file's header and the column emitted as `close`. `url_for(symbol)` builds
    `{SYMBOL}_History.csv` on `cdn-api.cboe.com`; `URL` (VIX) is unchanged. `plan` emits one
    request per configured symbol (VIX first, same params as before). A configured symbol with no
    layout is logged and skipped. `parser_version` goes to `2` (the base contract says bump on
    any `parse` change); VIX values are unchanged.
  - `plan_range(start, end, ctx)` (P-020): one request per symbol with `start`/`end`. `parse`
    filters to that window. End before start raises `ValueError`, as in FRED and Treasury.
  - `config.yaml`: instruments VIX9D, VIX3M, VIX6M, VXN, GVZ and SKEW (vol, kind index,
    `index_pts`, tier 3), all on dataset `vix_history`, so the existing freshness entry covers
    them.
  - Synthetic fixtures for the six files, copying the probed headers.
  - `tests/unit/sources/test_cboe_t47.py`: card table, layouts against the probe, plan, plan_range
    (two years, multi-month window, bad params), parse per fixture, cross-layout rejection,
    malformed SKEW, fetch per URL, then a local store through freshness, `BriefModel` and
    `build_bars`.
  - `docs/sources/cboe.md`: symbols, layouts, range planning, publication timing and the probe.
- Went wrong:
  - The live probe with `curl` in the shell was refused by the session's permission gate. I used
    the agent web-fetch tool instead. It returns text without a status code or statistics, so
    the row counts are estimates and min/max were not computed. `docs/sources/cboe.md` gives a
    one-line owner command for exact counts, min and max.
  - The probe found GVZ uses the single-column layout (`DATE,GVZ`) like SKEW. The plan only
    flagged SKEW.
  - Existing tests: `test_cboe.py::test_plan` asserted one request; it now asserts seven with VIX
    first. `test_config.py`'s instrument count goes from 36 to 42.
  - The worktree has no `.venv`; checks ran with the main checkout's venv and
    `PYTHONPATH=src:tests:.`.
- Decisions:
  1. One dataset (`vix_history`) for all Cboe symbols rather than a new one. It keeps VIX
     untouched and needs no new freshness entry; the name is historical.
  2. Freshness unchanged (`20:00` ET, lag 0). At 15:08 ET on 19 Nov every file ended at 18 Nov,
     which fits an after-close update. The exact posting time was not measured.
  3. The six new indices have no intraday feed, so the morning brief shows their previous close
     with "no move yet" (`query.overnight_changes` price family). Adding Yahoo quote feeds would
     give them a move, but Yahoo feeds are outside T47's Owns. Recorded as a follow-up.
