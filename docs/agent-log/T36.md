## 2026-11-18 · T36 Dashboard redesign: terminal workspace, tearsheet, headline-first system pages · planner (opus-5.5), owner-directed

- Did: redesigned the Streamlit dashboard at the owner's request, in the order the owner chose (Home first, then the rest), with apple-design and minimalist-ui as the design references and Castle Hook (a NY global-macro fund) as the target user.
  - Home is one dark-terminal workspace: market strip and biggest moves on top, a watchlist with search on the left, the selected instrument's chart (candles when open/high/low are consistent, else a line; volume; crosshair; ranges; compare rebased to 100; CSV download) and a 30-day small-multiples overview in the middle, and details on the right. Selection lives in the URL (`?id=`, `r`, `q`).
  - Instrument tearsheet: change over 1D/1W/1M/3M/YTD/1Y, a "Do the sources agree?" verdict under the price, every stored value per source/dataset/field/interval with as-of and fetch age, the tier ladder with like-for-like flags, 14 days of cross-checks, risk and range (20-day realised vol, latest move in sigma, drawdown, range), lineage, checks and corrections. Each statistic states how many days it needs when the store holds fewer.
  - The Instrument page (`app/pages/2_Instrument.py`) is folded into Home; its ladder, lineage and check history moved to `app/components/instrument.py`, its tests to `tests/unit/app/test_home.py`.
  - System pages lead with headline numbers, problems first: Data health (failing checks grouped by check and source), Sources (per-source cards, readable ages, switched-off sources left out), Cross checks (readable names, each check's latest real comparison, never-compared folded), Runs (reads the `runs` table so the newest run shows, durations, clearer columns). Top-bar navigation on every page.
- Went wrong:
  - Streamlit does not reload imported modules; several "it still looks old" reports were a server that needed a restart.
  - The first real-data click took ~16 s: each per-click query rebuilt a full in-memory DuckDB from the cached tables. Fixed with one shared, locked connection per process rebuilt every 60 s (`data.shared_connection`); clicks now take 1-2 s.
  - A synthetic fixture collision drew a giant fake candle; candles are now drawn only for days whose open/high/low agree with the close (`chart.candle_ok`), others as ticks.
  - Every cross-check's latest run was a skip, so the page claimed "0 agreeing"; it now reports each check's latest real comparison.
- Decisions:
  - Provenance rule kept: every figure still goes through `values.value_cell`; that is why the watchlist is HTML links, not an `st.dataframe`.
  - Hosted mode never reads tier 1: the bars, all-values, ladder and revisions queries exclude hidden tiers in SQL; cross-checks naming a source with a hidden-tier feed are withheld whole.
  - Altair (bundled with Streamlit) for the price chart; no new dependency.
  - Stooq is left out of Sources because it is disabled in `config.yaml` (owner decision).
- Size: far over the ~400-line guideline (about 2,500 lines added across 18 files, most of it tests and CSS); not split because the owner reviewed it live as one redesign.
- Follow-ups: phase 2 data (history backfill, daily bars for single stocks, macro/vol/positioning sources) and phase 3 ("ask the desk" AI) need owner decisions; pipeline findings are in PR #70.
- Review rounds: 0 so far.
